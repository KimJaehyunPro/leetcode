# **56. Merge Intervals**

**Difficulty**: Medium  
**Topics**: Sorting, Array Manipulation  
**Companies**: Google, Facebook, Microsoft

---

### **Problem Description**

Given an array of intervals where `intervals[i] = [starti, endi]`, merge all overlapping intervals and return an array of the non-overlapping intervals that cover all the intervals in the input.

### **Example 1**:

**Input**:
```plaintext
intervals = [[1, 3], [2, 6], [8, 10], [15, 18]]
```

**Output**:
```plaintext
[[1, 6], [8, 10], [15, 18]]
```

**Explanation**:
- Intervals `[1, 3]` and `[2, 6]` overlap, so we merge them into `[1, 6]`.
- The intervals `[8, 10]` and `[15, 18]` do not overlap with each other or any other intervals, so they remain unchanged.

### **Example 2**:

**Input**:
```plaintext
intervals = [[1, 4], [4, 5]]
```

**Output**:
```plaintext
[[1, 5]]
```

**Explanation**:
- Intervals `[1, 4]` and `[4, 5]` are considered overlapping because they share the endpoint `4`.
- We merge them into the interval `[1, 5]`.

---

### **Constraints**:

- `1 <= intervals.length <= 10^4`
- `intervals[i].length == 2`
- `0 <= starti <= endi <= 10^4`

---

### **Solution 1:**

```python
class Solution:
    def merge(self, intervals: List[List[int]]) -> List[List[int]]:
        # Sort intervals by their starting point
        intervals.sort(key=lambda interval: interval[0])

        merged_intervals = []  # To store the final merged intervals

        # Start with the first interval
        previous_interval = intervals[0]

        # Iterate through the rest of the intervals
        for current_interval in intervals[1:]:
            # Check if the current interval overlaps with the previous one
            is_overlapped = (previous_interval[1] >= current_interval[0])
            if is_overlapped:
                # Merge overlapping intervals by extending the end of the previous interval
                previous_interval[1] = max(previous_interval[1], current_interval[1])
            else:
                # No overlap, add the previous interval to the result
                merged_intervals.append(previous_interval)
                previous_interval = current_interval

        # Add the last interval to the result
        merged_intervals.append(previous_interval)

        return merged_intervals
```

### **Explanation**:

1. **Sorting**: 
   - The intervals are sorted based on their starting points. This helps in efficiently merging overlapping intervals since once sorted, overlapping intervals will be adjacent.

2. **Merging Intervals**:
   - We initialize the `previous_interval` with the first interval.
   - Then, we iterate through the remaining intervals.
     - If the current interval overlaps with the previous one (i.e., the start of the current interval is less than or equal to the end of the previous interval), we merge them by extending the `previous_interval`'s end to the maximum of the two intervals' ends.
     - If there’s no overlap, we add the `previous_interval` to the result and set the `previous_interval` to the current interval.

3. **Final Step**:
   - After the loop, we append the last interval (`previous_interval`) to the result list.

### **Time and Space Complexity**:

- **Time Complexity**: \(O(n \log n)\), where \(n\) is the number of intervals. The sorting step takes \(O(n \log n)\), and the iteration through the intervals takes \(O(n)\).
  
- **Space Complexity**: \(O(n)\), where \(n\) is the number of intervals. We are using an additional list (`merged_intervals`) to store the merged intervals.
