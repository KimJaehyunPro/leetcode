### Problem: 392. Is Subsequence

**Difficulty:** Easy  
**Topics:** Strings, Two Pointers  
**Companies:** [Various companies]

Given two strings `s` and `t`, return `true` if `s` is a subsequence of `t`, or `false` otherwise.

A **subsequence** of a string is a new string that is formed from the original string by deleting some (or none) of the characters, without disturbing the relative positions of the remaining characters. For example:
- `"ace"` is a subsequence of `"abcde"`.
- `"aec"` is **not** a subsequence of `"abcde"`.

---

### Example 1:
**Input:**  
`s = "abc"`, `t = "ahbgdc"`

**Output:**  
`true`

---

### Example 2:
**Input:**  
`s = "axc"`, `t = "ahbgdc"`

**Output:**  
`false`

---

### Constraints:
- `0 <= s.length <= 100`
- `0 <= t.length <= 10^4`
- `s` and `t` consist only of lowercase English letters.

---

### Follow-up:
Suppose there are a lot of incoming `s` values, say `s1, s2, ..., sk` where `k >= 10^9`, and you want to check one by one to see if `t` has its subsequence. In this case, how would you change your code?

### My Solution 1:

```python
class Solution:
    def isSubsequence(self, subsequence: str, sequence: str) -> bool:

        def find_subsequence_char_from_sequence(subsequence_char, sequence, first_possible_sequence_index):
            number_of_checks = 0

            # Iterate over the remaining portion of the sequence
            for sequence_char in sequence[first_possible_sequence_index:]:
                number_of_checks += 1
                is_subsequence_char_found = (subsequence_char == sequence_char)

                if is_subsequence_char_found:
                    # Update the index to continue from the next character
                    first_possible_sequence_index += number_of_checks
                    return True, first_possible_sequence_index

            return False, None

        first_possible_sequence_index = 0

        # Iterate over each character in the subsequence
        for subsequence_index, subsequence_char in enumerate(subsequence):
            is_subsequence_char_found, first_possible_sequence_index = find_subsequence_char_from_sequence(subsequence_char, sequence, first_possible_sequence_index)
            if not is_subsequence_char_found:
                return False

        return True
```

#### Runtime:
- **Time Complexity:** O(n), where `n` is the length of `sequence`. The method efficiently checks if `subsequence` is a subsequence of `sequence`.
- **Memory Complexity:** O(1), since we use constant space besides the input strings.

### My Solution 2:

```python
class Solution:
    def isSubsequence(self, sub_string: str, main_string: str) -> bool:

        sub_string_index = main_string_index = 0

        sub_string_len = len(sub_string)
        main_string_len = len(main_string)

        while (sub_string_index < sub_string_len) and (main_string_index < main_string_len):
            is_found = (sub_string[sub_string_index] == main_string[main_string_index])

            if is_found:
                sub_string_index += 1

            main_string_index += 1
            
        is_all_found = (sub_string_index == sub_string_len)

        return is_all_found
```

#### Runtime:
- **Time Complexity:** O(n), where `n` is the length of `main_string`. The algorithm loops through `main_string` while checking characters from `sub_string`.
- **Memory Complexity:** O(1), as it only uses a constant amount of extra space.
