## Problem Description

Given two strings `s` and `t`, determine if they are **isomorphic**.

Two strings `s` and `t` are considered **isomorphic** if the characters in `s` can be replaced to form `t`, while preserving the order of characters. In other words:
- All occurrences of a character must be replaced with another character.
- No two characters may map to the same character, but a character may map to itself.

---

## Example 1:
**Input**:
```plaintext
s = "egg", t = "add"
```

**Output**:
```plaintext
true
```

**Explanation**:
The strings `s` and `t` can be made identical by:
- Mapping `'e'` to `'a'`.
- Mapping `'g'` to `'d'`.

---

## Example 2:
**Input**:
```plaintext
s = "foo", t = "bar"
```

**Output**:
```plaintext
false
```

**Explanation**:
The strings `s` and `t` cannot be made identical, as `'o'` needs to be mapped to both `'a'` and `'r'`, which violates the one-to-one mapping rule.

---

## Example 3:
**Input**:
```plaintext
s = "paper", t = "title"
```

**Output**:
```plaintext
true
```

---

## Constraints:
- \(1 \leq s.length \leq 5 \times 10^4\)
- \(t.length = s.length\)
- `s` and `t` consist of any valid ASCII characters.

## My Solution

```python
class Solution:
    def isIsomorphic(self, str1: str, str2: str) -> bool:
        pairs: dict = {}

        for i in range(len(str1)):
            str1_char = str1[i]
            str2_char = str2[i]

            # Check if the current character in str1 has been mapped
            if str1_char in pairs:
                is_wrong_pair = (pairs[str1_char] != str2_char)
                if is_wrong_pair:
                    return False

            # Check if the current character in str2 is already mapped to a different character in str1
            elif str2_char in pairs.values():
                is_wrong_pair = (str1_char not in pairs) or (pairs[str1_char] != str2_char)
                if is_wrong_pair:
                    return False

            # Map the current characters from str1 to str2
            pairs[str1_char] = str2_char

        return True
```

---

## Explanation of the Solution

1. **Initial Setup**:
   - We initialize a dictionary `pairs` to store the mapping between characters from `str1` to `str2`.
   
2. **Iterating Over Characters**:
   - We loop through each character in `str1` and check if it has already been mapped to a corresponding character in `str2` using the `pairs` dictionary.

3. **Handling Mappings**:
   - If the character from `str1` has been mapped but doesn't match the expected character in `str2`, we return `False`.
   - Similarly, if the character from `str2` has been mapped to another character from `str1`, we also return `False`.

4. **Return True**:
   - If we complete the iteration without finding any conflicts, the strings are isomorphic, and we return `True`.

---

## Time and Space Complexity

### Time Complexity:
- The algorithm iterates through the characters of `str1` and `str2` once, so the time complexity is \(O(n)\), where \(n\) is the length of the strings.

### Space Complexity:
- The space complexity is \(O(n)\), as we are using a dictionary to store the mappings between characters, which can potentially store \(n\) key-value pairs.

# Possible Improvement

The current solution is already efficient and clear, but there are a few small improvements or optimizations you could consider, depending on your goals.

### 1. **Single Dictionary Approach**
   - The solution uses a dictionary to track mappings from `str1` to `str2` but also checks if characters in `str2` are already mapped to different characters. Instead of checking `str2_char in pairs.values()` (which requires scanning the values of the dictionary), we can use two separate dictionaries: one to track mappings from `str1` to `str2` and another to track mappings from `str2` to `str1`. This eliminates the need for checking if a character is already mapped in `str2`.

   Here's an improved version:

```python
class Solution:
    def isIsomorphic(self, str1: str, str2: str) -> bool:
        map_s_to_t = {}
        map_t_to_s = {}

        for char_s, char_t in zip(str1, str2):
            # Check if there's a mismatch in the mapping from str1 to str2
            if map_s_to_t.get(char_s, char_t) != char_t:
                return False
            # Check if there's a mismatch in the mapping from str2 to str1
            if map_t_to_s.get(char_t, char_s) != char_s:
                return False
            
            # Store the mappings
            map_s_to_t[char_s] = char_t
            map_t_to_s[char_t] = char_s

        return True
```

### Why This Is An Improvement:
- **Two dictionaries**: We now track both mappings (`str1 -> str2` and `str2 -> str1`). This allows us to avoid the costly `values()` lookup.
- **Efficient matching**: The `zip` function lets us loop through both strings simultaneously, improving clarity.
- **Eliminated unnecessary checks**: By directly checking the mappings in both directions, we avoid extra conditionals.

### 2. **Avoiding Use of `get` (Optional)**
   - If you are sure the mappings will be valid, you could use direct dictionary lookups instead of `get` to improve performance slightly. However, this may raise a `KeyError` if the key doesn't exist, so it’s typically safer to stick with `get`.

## **Better Solution 1:**

```python
class Solution:
    def isIsomorphic(self, s: str, t: str) -> bool:
        return len(set(zip(s, t))) == len(set(s)) == len(set(t))
```

### **Explanation**:

- **`zip(s, t)`**: This pairs up each character from the two strings `s` and `t` into tuples. For example, `zip("egg", "add")` would produce `[('e', 'a'), ('g', 'd'), ('g', 'd')]`.
  
- **`set(zip(s, t))`**: This converts the list of tuples into a set, removing any duplicate mappings. For the above example, it would result in `{('e', 'a'), ('g', 'd')}`.

- **`set(s)` and `set(t)`**: These sets ensure that each character in `s` and `t` is mapped to a unique character. If a character in `s` maps to two different characters in `t`, or vice versa, the length of `set(s)` or `set(t)` will be less than expected.

- **Final Condition**: If the length of the set of character pairs is equal to the length of the set of characters from both strings (`set(s)` and `set(t)`), it means each character has a unique mapping to another character, satisfying the isomorphic condition.

### **Time and Space Complexity**:

- **Time Complexity**: \(O(n)\), where \(n\) is the length of the strings. The `zip` operation iterates over both strings, and the set operations (converting to set) each take \(O(n)\) time.
  
- **Space Complexity**: \(O(n)\), as sets are used to store unique character pairs and individual characters.

## **Solution 2:**

```python
class Solution:
    def isIsomorphic(self, s: str, t: str) -> bool:
        s_to_t = {}  # Map from characters in s to characters in t
        t_to_s = {}  # Map from characters in t to characters in s

        # Iterate through paired characters from s and t
        for char_s, char_t in zip(s, t):
            # Check if the character from s is already mapped
            if char_s in s_to_t:
                # If it's mapped incorrectly, return False
                if s_to_t[char_s] != char_t:
                    return False
            else:
                # If not mapped, add the mapping
                s_to_t[char_s] = char_t

                # Check if the character from t is already mapped to a different character in s
                if char_t in t_to_s:
                    if t_to_s[char_t] != char_s:
                        return False
                else:
                    t_to_s[char_t] = char_s

        # Return True if all mappings are valid
        return True
```

### **Explanation**:

1. **Mapping Characters**:
   - Two dictionaries are used: `s_to_t` for mapping characters from string `s` to string `t`, and `t_to_s` for mapping characters from `t` to `s`. These two mappings ensure that each character in `s` maps to exactly one character in `t`, and vice versa.

2. **Checking for Mismatched Mappings**:
   - During the iteration, if a character in `s` has already been mapped, we check whether its current mapping is consistent with the corresponding character in `t`. If not, we return `False`.
   - Similarly, if a character in `t` has already been mapped to a different character in `s`, the strings cannot be isomorphic, and we return `False`.

3. **Early Return**:
   - If any inconsistency is found during the iteration, the function returns `False` immediately.
   - If the iteration completes without any issues, the function returns `True`, indicating that the strings are isomorphic.

- **Time Complexity**: \(O(n)\), where \(n\) is the length of the strings `s` and `t`. We iterate over the strings once, and each dictionary operation (insertion and lookup) is \(O(1)\) on average.
  
- **Space Complexity**: \(O(n)\), as we use two dictionaries to store the mappings, where \(n\) is the length of the strings.
