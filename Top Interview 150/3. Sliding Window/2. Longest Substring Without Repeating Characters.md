## Problem: Longest Substring Without Repeating Characters

**Difficulty**: Medium  
**Topics**: String, Sliding Window, Hash Table  
**Companies**: Google, Amazon, Microsoft, Facebook

### Problem Description

Given a string `s`, find the length of the longest substring without repeating characters.

### Example 1:

**Input**:  
`s = "abcabcbb"`

**Output**:  
`3`

**Explanation**: The answer is `"abc"`, with the length of 3.

---

### Example 2:

**Input**:  
`s = "bbbbb"`

**Output**:  
`1`

**Explanation**: The answer is `"b"`, with the length of 1.

---

### Example 3:

**Input**:  
`s = "pwwkew"`

**Output**:  
`3`

**Explanation**: The answer is `"wke"`, with the length of 3.  
Notice that the answer must be a substring. `"pwke"` is a subsequence, not a substring.

---

### Constraints:
- `0 <= s.length <= 5 * 10^4`
- `s` consists of English letters, digits, symbols, and spaces.

---

## Solution:
Here is your original code block without any edits:

```python
class Solution:
    def lengthOfLongestSubstring(self, s: str) -> int:

        if len(s) == 0:
            return 0

        char_to_index_dict = {}
        substring_beginning_index = substring_ending_index = 0
        max_substring_length = 1

        for current_char_index, current_char in enumerate(s):

            current_substring_length = 1 + (substring_ending_index - substring_beginning_index)

            if (current_char in char_to_index_dict):

                previous_char_index = char_to_index_dict[current_char]
                char_to_index_dict[current_char] = current_char_index

                # If the previous same char is in the substring, start the substring right after from that previous same char.
                if (substring_beginning_index <= previous_char_index):
                    substring_beginning_index = previous_char_index + 1
                    current_substring_length -= 1

            else:
                char_to_index_dict[current_char] = current_char_index

            max_substring_length = max(max_substring_length, current_substring_length)

            substring_ending_index += 1

        return max_substring_length
```

### Explanation:
- **Sliding Window Technique**: We use a sliding window to represent the current substring. As we iterate over the string, we expand the window by moving the end of the window (`substring_ending_index`). If we encounter a repeating character, we adjust the window's start (`substring_beginning_index`) to exclude the first occurrence of that character.
  
- **Character Index Map**: We store the last index of each character we encounter using a dictionary (`char_to_index_dict`). This helps in determining whether a character is repeated within the current window and allows us to adjust the window boundaries accordingly.

- **Time Complexity**: O(n), where `n` is the length of the string. Each character is visited at most twice (once when expanding the window and once when adjusting the window).
  
- **Space Complexity**: O(min(n, m)), where `n` is the length of the string and `m` is the size of the character set (in this case, it's the number of unique characters).


### Suggested Improvements:

1. **Initial Max Substring Length**:
   - The `max_substring_length` is initialized to 1, but it should be initialized to 0, because if the input string is empty, the correct return value should be `0` rather than `1`. 
   
2. **Unused Variable**:
   - The `substring_ending_index` is being incremented in the loop but is not used directly. Since you're already calculating the substring length based on the `substring_beginning_index` and `current_char_index`, you can remove this variable to simplify the code.
   
3. **Current Substring Length Calculation**:
   - `current_substring_length` is calculated as `1 + (substring_ending_index - substring_beginning_index)`. This calculation is fine, but it's slightly redundant. You can directly use the difference `current_char_index - substring_beginning_index + 1` to calculate the length of the current substring. This would simplify the code and make it clearer.
   
4. **Dictionary Updates**:
   - When you encounter a character that's already in the dictionary, you update it using `char_to_index_dict[current_char] = current_char_index`. However, you may also want to explicitly store the latest index of the character, even when you don't shift the window (i.e., when the previous occurrence of the character isn't inside the window).
   
5. **Efficiency**:
   - While the algorithm is already efficient (O(n) time complexity), you can slightly improve readability by avoiding unnecessary conditional checks like `if (substring_beginning_index <= previous_char_index):` and just adjusting the window based on the last seen index of the character.

### Revised Version (with improvements):


```python
class Solution:
    def lengthOfLongestSubstring(self, s: str) -> int:
        if len(s) == 0:
            return 0

        char_to_index_dict = {}
        substring_beginning_index = 0
        max_substring_length = 0

        for current_char_index, current_char in enumerate(s):
            # If the character was seen within the current window, move the beginning of the window
            if current_char in char_to_index_dict and char_to_index_dict[current_char] >= substring_beginning_index:
                substring_beginning_index = char_to_index_dict[current_char] + 1
            
            # Update the dictionary with the most recent index of the current character
            char_to_index_dict[current_char] = current_char_index

            # Calculate the current length of the substring
            max_substring_length = max(max_substring_length, current_char_index - substring_beginning_index + 1)

        return max_substring_length
```
