## [169. Majority Element](https://leetcode.com/problems/majority-element/)

### 📝 Problem Description

Given an array `nums` of size , return the **majority element**.

The majority element is defined as the value that appears more than  times. You may safely assume that the majority element **always exists** in the input array.

> **Challenge:** Can you solve this in ** time** and ** space**?

---

### 💡 Examples

* **Example 1:**
* **Input:** `nums = [3, 2, 3]`
* **Output:** `3`


* **Example 2:**
* **Input:** `nums = [2, 2, 1, 1, 1, 2, 2]`
* **Output:** `2`



---

### 🛠️ Constraints

* n == nums.length
* 1 <= n
---

### 🚀 Boyer-Moore Voting Algorithm

This algorithm works by maintaining a `candidate` and a `count`. When the `count` is zero, we pick a new candidate. If we see the same number again, we increment the count; if we see a different number, we decrement it. Since the majority element appears more than half the time, it will always remain as the survivor.

```python
class Solution:
    def majorityElement(self, nums: List[int]) -> int:
        candidate = None
        count = 0

        for num in nums:
            # If the current candidate is "voted out," pick a new one
            if count == 0:
                candidate = num
            
            # Increment count for matches, decrement for different values
            count += 1 if num == candidate else -1

        return candidate

```

### 📊 Complexity Analysis

* **Time Complexity:** **** — We only pass through the array one time.
* **Space Complexity:** **** — We only store two variables (`candidate` and `count`), regardless of the input size.
